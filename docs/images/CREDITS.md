# Screenshot images

The screenshots show Wearlog running in a headless Chromium browser against a temporary local Worker. The garments and wear counts are demo data.

Shirt photos are used under the [Pexels licence](https://www.pexels.com/license/) and cropped through Wearlog's photo importer:

- [Minimalist green T-shirt on a wooden hanger](https://www.pexels.com/photo/fashion-shopping-indoors-no-people-9594692/)
- [Flat lay of mint green T-shirt with cotton stems](https://www.pexels.com/photo/flat-lay-of-mint-green-t-shirt-with-cotton-stems-34156905/)
- [A basic white T-shirt](https://www.pexels.com/photo/a-basic-white-t-shirt-18186106/)
- [Basic black and white T-shirts](https://www.pexels.com/photo/basic-black-and-white-t-shirts-18186105/)
- [Orange T-shirt held on a hanger](https://www.pexels.com/photo/orange-t-shirt-held-on-hanger-isolated-36392069/)
- [Minimalist flat lay of cotton T-shirts](https://www.pexels.com/photo/minimalist-flat-lay-of-cotton-t-shirts-34156906/)

Run `npm run build`, then `python scripts/screenshots.py` to regenerate. This downloads the source photos to a temporary folder and creates demo records only in local test storage.
